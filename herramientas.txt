#  CATÁLOGO DE HERRAMIENTAS — Grupo Empresarial La Ofrenda
#  Fuente única del portal. Una herramienta por línea:
#
#      nombre | área | descripción | URL
#
#  Reglas:
#  - El carácter | está RESERVADO como separador. No lo use dentro de
#    ningún campo; en su lugar use "/", "-" o ",".
#  - Los cuatro campos son obligatorios.
#  - Solo se aceptan enlaces que empiecen por https://
#  - Las líneas vacías y las que empiezan por # se ignoran.
#  - Las herramientas se muestran en el mismo orden de este archivo.
#  - El área agrupa sin distinguir mayúsculas ni tildes, pero escríbala
#    siempre igual para que se vea uniforme (p. ej. "Operaciones").
#  - Una línea con errores se omite y el motivo queda en la consola
#    del navegador (F12); las demás cargan normalmente.
